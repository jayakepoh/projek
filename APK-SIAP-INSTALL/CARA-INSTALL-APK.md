# 📱 Panduan Pasang File APK ke HP Android

File APK kedua game sudah berhasil dibuat dan siap di-install langsung di HP Android:

1. **⭐ Bintang Jatuh**: `Bintang-Jatuh.apk` (Ukuran: ±12.6 MB)
2. **🏓 Ping Pong 3D**: `Ping-Pong-3D.apk` (Ukuran: ±12.6 MB)

APK membutuhkan Android 7.0 (API 24) atau lebih baru. Perbarui Android System WebView atau Chrome untuk kompatibilitas terbaik.
Ping Pong terbuka dalam mode lanskap layar penuh; gunakan tombol panah pada sisi kiri atau kanan untuk menggerakkan bet.

Jika game menampilkan layar hitam, perbarui **Android System WebView** dan **Google Chrome** melalui Play Store, hapus/uninstall versi game sebelumnya, lalu pasang ulang APK terbaru dari folder ini.
Pembaruan ini juga memperbaiki pemuatan layar game. Jika APK dikirim melalui WhatsApp, kirim ulang file terbaru dari folder ini; file APK yang sudah ada di chat tidak ikut diperbarui.

---

## Cara Pasang ke HP:

### Langkah 1: Kirim file ke HP
Pilih salah satu cara yang paling mudah:
- **Kabel Data USB**: Sambungkan HP ke PC/laptop, pindahkan file APK ke folder *Download* di HP.
- **WhatsApp Web**: Kirim file APK ke chat sendiri di WhatsApp Web, lalu buka & unduh di HP.
- **Google Drive**: Upload file APK ke Google Drive dari PC, lalu buka dan download di aplikasi Google Drive di HP.

### Langkah 2: Install di HP
1. Buka file manager di HP, cari file `.apk` yang sudah dikirim (biasanya di folder *Download*).
2. Ketuk file `.apk` untuk mulai install.
3. Jika muncul notifikasi **"Demi keamanan, ponsel tidak diizinkan menginstal aplikasi tidak dikenal dari sumber ini"**:
   - Ketuk **Setelan / Settings**.
   - Aktifkan **Izinkan dari sumber ini / Allow from this source**.
   - Tekan tombol kembali lalu ketuk **Instal**.
4. Selesai! Ikon game akan langsung muncul di menu aplikasi HP dan bisa dimainkan **100% offline tanpa internet**.
